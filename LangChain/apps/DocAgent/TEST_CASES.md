## 关键发现

### 已解决

| 问题 | 修复 | 验证 |
|:-----|:-----|:-----|
| chunk tag 重复 | splitByHeadings | L3/L4 通过 |
| 9200% 分数 bug | 归一化 reranker | 所有测试正确显示 |
| JSON 解析失败（换行符） | sanitizeJSON | Q7/Q8/Q9 不再解析失败 |
| 不必要的 summarize | Prompt 规则 + 新示例 | Q11 已改善 |
| 低分噪音干扰 | filter < 50% chunk | Q13/Q17 不再死循环 |

### 未解决

| 问题 | 优先级 | 说明 |
|:-----|:-------|:-----|
| Q1 只答 3/8 框架 | P0 | Observation 过长，LLM 读不完 9 个 chunk |
| Q8 summarize 偏题 | P1 | summarize 工具把"对比表"变成了"例子"视角 |
| Q6/Q10/Q16 还绕路 summarize | P2 | Prompt 规则已加强，但 LLM 有时仍不听话 |
