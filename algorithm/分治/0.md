# 分治（divide and conquer），全称分而治之，是一种非常重要且常见的算法策略。分治通常基于递归实现，包括“分”和“治”两个步骤。

- 分（划分阶段）：递归地将原问题分解为两个或多个子问题，直至到达最小子问题时终止。
- 治（合并阶段）：从已知解的最小子问题开始，从底至顶地将子问题的解进行合并，从而构建出原问题的解。

## .如何判断分治问题

- 一个问题是否适合使用分治解决，通常可以参考以下几个判断依据。
- 问题可以分解：原问题可以分解成规模更小、类似的子问题，以及能够以相同方式递归地进行划分。
- 子问题是独立的：子问题之间没有重叠，互不依赖，可以独立解决。
- 子问题的解可以合并：原问题的解通过合并子问题的解得来。
  显然，归并排序满足以上三个判断依据。
- 问题可以分解：递归地将数组（原问题）划分为两个子数组（子问题）。
- 子问题是独立的：每个子数组都可以独立地进行排序（子问题可以独立进行求解）。
- 子问题的解可以合并：两个有序子数组（子问题的解）可以合并为一个有序数组（原问题的解）。

## .分治解题模版

### 三步套路

写分治题目时，按顺序回答三个问题，答案就是代码骨架：

1. **终止条件（最小子问题）**：什么时候不需要再分，直接返回已知解？
   - 常见写法：`lo >= hi`（只剩一个元素）、`n === 1`、`node === null`。
2. **分（划分阶段）**：如何把原问题切分成规模更小、形式相同的子问题？
   - 常见写法：取中点 `mid = (lo + hi) >> 1` 二分、快排的 partition、树的左右子树。
3. **治（合并阶段）**：拿到子问题的解后，如何合并出原问题的解？
   - 常见写法：归并两个有序数组、用左右子树的结果构造当前节点、`2^half * 2^half`。

```javascript
/**
 * 分治通用模版（伪代码骨架）
 * @param {*} problem 原问题（如数组区间 [lo, hi]、子树节点等）
 * @return {*} 原问题的解
 */
function divideAndConquer(problem, lo, hi) {
    // 1. 终止条件：问题小到可以直接求解时，返回基础解
    if (lo >= hi) {
        return baseCase(problem); // 最小子问题的已知解
    }

    // 2. 分：将问题划分为若干独立的子问题
    const mid = (lo + hi) >> 1;
    const leftResult = divideAndConquer(problem, lo, mid);    // 解决左半部分
    const rightResult = divideAndConquer(problem, mid + 1, hi); // 解决右半部分

    // 3. 治：合并子问题的解，得到当前层的解
    return merge(leftResult, rightResult, problem);
}
```

### 以归并排序为例套模版

```javascript
/**
 * @param {number[]} nums
 * @param {number} lo
 * @param {number} hi
 * @return {number[]} 有序数组
 */
function mergeSort(nums, lo, hi) {
    // 1. 终止条件：区间只剩 0 或 1 个元素，天然有序
    if (lo >= hi) return [nums[lo]].filter((v) => v !== undefined);

    // 2. 分：一分为二
    const mid = (lo + hi) >> 1;
    const left = mergeSort(nums, lo, mid);
    const right = mergeSort(nums, mid + 1, hi);

    // 3. 治：合并两个有序子数组
    const merged = [];
    let i = 0, j = 0;
    while (i < left.length && j < right.length) {
        merged.push(left[i] <= right[j] ? left[i++] : right[j++]);
    }
    return [...merged, ...left.slice(i), ...right.slice(j)];
}
```

### 注意事项

- **每层递归规模必须严格缩小**，否则会无限递归（如快排要把 pivot 排除出子问题）。
- **子问题划分要覆盖全且不重叠**：`[lo, mid]` 与 `[mid + 1, hi]` 加起来正好是 `[lo, hi]`。
- 分治解法的复杂度可用**主定理**估算：二分 + 线性合并 ⇒ `T(n) = 2T(n/2) + O(n) ⇒ O(n log n)`；只递归一半 ⇒ `O(log n)`（如次幂函数）。
- 若子问题**有重叠**（如斐波那契、不同路径），分治会重复计算，应改用动态规划或加记忆化。
